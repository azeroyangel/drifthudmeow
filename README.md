# driftmeow

compact drift hud
anime style lol

## features

### compact hud
* speed indicator
* current gear
* engine rpm
* steering angle
* pedal and handbrake inputs
* live drift angle
* drift duration timer

### practice history
* automatic session recording
* tracking by track, layout, and car
* personal bests repository
* recent runs history
